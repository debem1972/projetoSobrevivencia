# projetoSobrevivencia
Bem vindo ao projeto SurvivalManager!
Aplicação web para gerenciamento de estoque de insumos para sobrevivência.
Aqui, o sobrevivencialista, poderá cadastrar todos os seus insumos necessários para sobrevivência, controlar a data de validade dos perecíveis automaticamente mediante gestão do próprio sistema.
poderá acompanhar pelo dashboard, as informações importantes como os tipos de insumos possui no estoque, se há produtos a vencer,as quantidades dos ítens quanto a unidade e quanto a massa e volume total dos insumos.
possui versões em inglês, espanhol e mandarin, além de português do Brasil.
Irei ainda implementar outras funcionalidades, mas com o que já tem, dá para ser utilizado tranquilamente. 
Modo de usar:
1 - Cadastre os insumos e exporte o arquivo JSON gerado automaticamente para o seu device, pc, tablet, smartphone, pois utiliza o IndexedDB, banco de dados do browser.
2 - Sempre que realizar qualquer adição, edição ou deletar algum ítem, exporte o arquivo salvo e substitua pelo antigo de mesmo nome salvo em seu device. manterá assim, sempre atualizado seu banco de dados.
possui também links de sites que considero úteis à sobrevivência.
